3. Buttons (hard constraint)

Shared rules on every live button

  • Shape: pill. The radius is set per widget, anywhere from 750px to 1000px, which all render as a full pill.
  • Border: 1px top, 2px right, 2px bottom, 1px left, solid. That offset "hand drawn shadow" edge is the signature detail.
  • Font: Oswald, uppercase, line height 1.0
  • Hover: grows to scale(1.1) over transform .5s (Elementor "Grow" animation). Some buttons also swap their fill on hover (see variants below).
  • Focus: same state as hover, plus a 2px solid black outline (from the accessibility plugin)
  • Program pills: scale(1.12) + box-shadow 0 3px 4px rgba(0,0,0,.18), easing cubic-bezier(.34,1.56,.64,1)
